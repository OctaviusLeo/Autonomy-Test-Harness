# Autonomy Test Harness

Scenario-based test harness that drives Nav2 and its minimal TurtleBot 4 simulation
(ROS 2 Jazzy, Gazebo Harmonic) through randomized, versioned Scenarios, injects
scheduled lidar faults, and judges each run from simulator ground truth.

This repository is private: no public license, no packaging, no public releases.

This README is a placeholder until `scripts/build_docs.py` generates it from
`docs/README.template.md` and the files under `results/`.
